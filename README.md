# القرآن الكريم مباشر — v5.3.7

تطبيق PWA عربي (HTML/CSS/JS بدون إطار): بث إذاعات القرآن، تلاوات كاملة (mp3quran.net)، أذكار، سبحة، مواقيت الصلاة، بوصلة القبلة، مفضلة وإعدادات، وضع فاتح/داكن/نظام، يعمل دون اتصال.
الموقع: https://qurankareem.live (GitHub Pages، CNAME = `qurankareem.live`).

## ما أُصلح وحُسِّن
التفاصيل الكاملة في `CHANGELOG_FINAL.md`. باختصار: 3 أخطاء حرجة (الموقع، إعادة جلب IP، حلقة البوصلة)، 5 رئيسية (تباين الرواية النشطة، ازدحام القائمة السفلية، تصادم رسائل السبحة، استعادة التلاوة، DST)، وتحسينات في بانر التثبيت وSW.

## الهيكل
- `index.html` — الصفحة والـ SEO والبنية؛ `css/styles.min.css` — نظام التصميم (متغيرات دلالية `--color-*` + أسماء قديمة كمرادفات).
- `js/app.js` — المُنسّق الرئيسي (راديو، مفضلة، سبحة، أذكار، تنقل). كبير ويُقسَّم تدريجيًا لا دفعة واحدة.
- خدمات وواجهات منفصلة: `prayerService/ui`، `qiblaService/UI`، `locationService`، `recitationService/UI`، `pwa-install`، `ui-enhancements`.
- `sw.js`، `manifest.json`، `offline.html`، `vendor/` (hls وadhan محليًا)، `js/__tests__` (حساب القبلة).

## PWA وأوفلاين
networkFirst بمهلة 1800ms مع `cache:'no-cache'` للأصول والصفحات؛ cacheFirst لبقية الملفات؛ البث المباشر وواجهات API تتجاوز الـSW. تلاوات محفوظة يدويًا تُخدَّم من كاش مخصص. التحديث: toast + `SKIP_WAITING` بموافقة المستخدم فقط حتى لا ينقطع الصوت. بانر التثبيت: بعد 15ث، يحترم الإغلاق 14 يومًا، تعليمات يدوية حين لا يتوفر `beforeinstallprompt`.

## الأداء
Qibla وHLS وعرض قائمة القرّاء كلها كسولة. الخطوط بنمط preload غير حاجب. لم يُقَس الأداء في هذه الجولة.

## تجربة الاستخدام وإمكانية الوصول
قائمة سفلية بستة عناصر أساسية؛ الثانوي في قائمة الرأس. حالة الاختيار بخلفية خفيفة وحد وعلامة ✓ (لا أخضر مشبع). RTL، `prefers-reduced-motion`، `focus-visible`، `aria-current`، أهداف لمس 44px على اللمس لعناصر محددة.

## الأمان
لا `eval`/`document.write`/`new Function`. بيانات الـAPI (أسماء القرّاء، المدينة/الدولة) تُهرَّب قبل `innerHTML`. التخزين المحلي يُتحقق منه (ثيم غير صالح يعود للداكن).
