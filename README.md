# القرآن الكريم مباشر

تطبيق ويب تقدّمي (PWA) خفيف بالكامل — بدون خادم، بدون خطوة بناء (build step)، بدون أي إطار عمل (framework). HTML وCSS وJavaScript خالص، يعمل من أي استضافة ملفات ثابتة (GitHub Pages، Netlify، أو حتى فتح الملف مباشرة).

## المميزات

- **إذاعات القرآن الكريم** — بث مباشر لعشرات الإذاعات (رسمية وقراءة)، مع دعم HLS وخادم احتياطي تلقائي عند انقطاع أي بث.
- **التلاوات** — تصفح حسب الرواية والقارئ والسورة، مع مشغّل مستقل يعمل بالتوازي (ومنفصل تمامًا) عن مشغّل الإذاعات.
- **مواقيت الصلاة** — حساب دقيق حسب الموقع الجغرافي التلقائي، مع خيار المذهب الفقهي لحساب وقت العصر، وتنبيه صوتي عند دخول الوقت.
- **بوصلة اتجاه القبلة** — حساب محلي بالكامل لاتجاه القبلة (بدون أي API خارجي)، بوصلة حيّة تستخدم حساس اتجاه الجهاز، تعمل بدون إنترنت بعد أول تحديد للموقع.
- **الأذكار** — أذكار الصباح والمساء مع عدّاد تقدّم يومي يُصفَّر تلقائيًا كل يوم.
- **السبحة الرقمية** — عدّاد تسبيح بسيط مع أهداف قابلة للتخصيص.
- **يعمل بدون إنترنت** — عبر Service Worker، بعد أول زيارة ناجحة.
- **وضعان بصريان** — داكن وفاتح، بهوية بصرية ذهبية/زمردية متسقة.

## أحدث التحسينات

**الأداء:**
- إزالة `backdrop-filter` (تأثير ضبابي مكلف على المعالج الرسومي) من أكثر عناصر الصفحة تكرارًا.
- تحميل مكتبة HLS.js (~400 كيلوبايت) عند الحاجة الفعلية فقط (أول تشغيل لإذاعة تحتاجها)، بدل تحميلها لكل زائر.
- استضافة مكتبتَي HLS.js وAdhan.js محليًا (مجلد `vendor/`) بدل الاعتماد على CDN خارجي.
- تأخير بسيط (debounce) على خانات البحث لتفادي إعادة رسم القوائم الطويلة مع كل ضغطة زر.
- إصلاح سكريبت كان يوقف تحميل الصفحة (`defer` مفقود).

**إصلاحات وظيفية:**
- إصلاح المشغّل العائم (Mini Player): كان يعرض معلومات الإذاعة ويتحكم فيها حتى أثناء تشغيل تلاوة فعليًا؛ أصبح يتعرّف على المصدر النشط فعليًا (إذاعة أو تلاوة) ويتحكم في الصحيح دائمًا.
- إصلاح تباين الألوان في الوضع الفاتح ليتوافق مع معايير إتاحة الوصول (WCAG).
- مساحات لمس مريحة (44×44) على الأجهزة اللمسية فقط، بدون أي تأثير على تصميم سطح المكتب.

**الهوية البصرية:**
- زخرفة هندسية إسلامية خفيفة في خلفية التطبيق.
- توحيد خط العنوان الرئيسي مع خطوط عناوين الأقسام (Amiri).
- تناسق كامل لمجموعة الأيقونات في شريط التنقل وعناوين الأقسام.

## البنية

```
index.html          الصفحة الوحيدة — كل الأقسام داخلها
css/styles.min.css   تنسيقات التطبيق كاملة
js/
  app.js             محرك الإذاعات + الحالة العامة + شريط التنقل
  recitationUI.js     واجهة ومنطق قسم التلاوات
  recitationService.js  جلب بيانات الروايات/القراء/السور
  prayerService.js    حساب مواقيت الصلاة (محليًا + خادم احتياطي)
  qiblaService.js     رياضيات بوصلة القبلة (خالصة، بلا DOM)
  qiblaUI.js           واجهة شاشة بوصلة القبلة + حساسات الجهاز
  locationService.js   تحديد الموقع الجغرافي (GPS/IP) والتخزين المؤقت
  ui.js                واجهة قسم مواقيت الصلاة
  ui-enhancements.js    تحسينات تفاعل عامة
  pwa-install.js        بانر تثبيت التطبيق
  __tests__/           اختبارات رياضية آلية (Node، بدون متصفح)
vendor/               مكتبات خارجية مستضافة محليًا (HLS.js، Adhan.js)
sw.js                Service Worker — التخزين المؤقت والعمل بدون إنترنت
manifest.json        بيانات تثبيت PWA
```
