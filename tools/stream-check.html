فحص روابط البث

يختبر كل محطة بنفس محرّك التطبيق (hls.js للمحطات ‎.m3u8‎ وعنصر الصوت للباقي) على نفس الموقع وتحت نفس سياسة CSP، ثم يجرّب الخادم الاحتياطي إن فشل الأساسي. الصوت مكتوم أثناء الفحص. اضغط «ابدأ» ثم انسخ التقرير وأرسله.

اختبار رابط مخصّص

الصق رابط بث (‎.m3u8‎ أو mp3/aac) لتجربته بنفس المحرّك — مفيد لاختبار روابط تجدها في المواقع الرسمية (مثل إذاعة القرآن في دبي أو أبوظبي) قبل إضافتها للتطبيق. طريقة العثور على الرابط: افتح صفحة البث الرسمية ← F12 ← Network ← اكتب m3u8 أو mp3 أو aac في المرشّح ← شغّل البث ← انسخ الرابط الظاهر.
